ค่าตั้งค่าใน spark.read.csv()  อ่านมาเป็น DataFrame
    header=True: ถ้าตั้งค่าเป็น True จะบอกให้ PySpark ว่าแถวแรกของไฟล์ CSV เป็นชื่อคอลัมน์ (header)
    inferSchema=True: ถ้าตั้งค่าเป็น True PySpark จะพยายามเดาประเภทข้อมูลของแต่ละคอลัมน์จากข้อมูลในไฟล์ CSV
                    : ถ้าตั้งค่าเป็น False จะถือว่าทุกคอลัมน์เป็น StringType โดยอัตโนมัติ
    sep: ใช้เพื่อกำหนดตัวแบ่ง (delimiter) สำหรับข้อมูลในไฟล์ เช่น ถ้าใช้ sep=";" สำหรับไฟล์ที่ใช้เครื่องหมาย ; เป็นตัวแบ่ง
    quote: ใช้กำหนดตัวอักษรที่ใช้ในการอ้างอิงค่าข้อมูล เช่น ถ้าใช้เครื่องหมาย quote='"' เป็นตัวอักษรอ้างอิง
            ช่วยให้ PySpark เข้าใจว่าข้อมูลที่อยู่ในเครื่องหมายคำพูดเป็นค่าทั้งหมดแม้ว่าจะมีการใช้ตัวแบ่งภายใน
    escape: ใช้เพื่อกำหนดตัวอักษรที่ใช้สำหรับการหลีกเลี่ยง เช่น escape="\\" เพื่อจัดการกับค่าในไฟล์ที่มีตัวอักษร quote
    nullValue: เช่น  nullValue="NA" คือค่าที่อ่านในไฟล์เป็น NA จะเเปลงเป็นค่า null
    mode: ใช้กำหนดโหมดการอ่านข้อมูล เช่น DROPMALFORMED (ลบแถวที่มีข้อมูลผิดรูปแบบ เช่น ค่าบางตัวหายไป) หรือ 
          FAILFAST (หยุดการอ่านทันทีเมื่อเจอข้อมูลผิดรูปแบบ)
    encoding: ใช้กำหนดการเข้ารหัสของไฟล์ เช่น UTF-8, ISO-8859-1 = encoding="UTF-8"

ประเภทข้อมูลที่ใช้ใน .cast()
    **** ใช้ double (ในรูปแบบสตริง) เมื่อคุณกำลังทำงานกับการแปลงประเภทข้อมูลใน DataFrame ในขณะที่ใช้ 
    DoubleType() จะใช้ในกรณีที่คุณกำลังตั้งค่าชนิดข้อมูลของคอลัมน์ใน schema ของ DataFrame *
    IntegerType(): เก็บค่าเลขจำนวนเต็ม เช่น 1, 2, -5   integer
    LongType(): เก็บค่าเลขจำนวนเต็มขนาดใหญ่           bigint
    FloatType(): เก็บค่าจำนวนจริงที่มีทศนิยม เช่น 1.23    float
    DoubleType(): เก็บค่าจำนวนจริงที่มีทศนิยมที่มีความแม่นยำสูงกว่าประเภท FloatType double
    StringType(): เก็บค่าข้อความ เช่น "hello world" string
    BinaryType(): เก็บข้อมูลแบบไบนารี (binary data) เช่น ไฟล์ภาพ เสียง binary
    DateType(): เก็บวันที่ เช่น 2024-10-26 date
    TimestampType(): เก็บวันที่และเวลาพร้อมเขตเวลา เช่น 2024-10-26 13:45:00 timestamp
    BooleanType(): เก็บข้อมูล Boolean (True/False) เช่น True, False boolean
    ArrayType(elementType): เก็บข้อมูลเป็น Array โดยกำหนดประเภทของข้อมูลได้ เช่น ArrayType(StringType())

1. Logistic Regression Parameter
        maxIter: กำหนดจำนวนรอบสูงสุดที่ใช้ในการฝึกโมเดล
        regParam: ค่าพารามิเตอร์การปรับน้ำหนัก (regularization) เพื่อป้องกันการเกิด overfitting
        elasticNetParam: ใช้เพื่อผสมระหว่าง L1 และ L2 regularization (0 = L2, 1 = L1)
        tol: ค่า tolerance กำหนดความแม่นยำในการหยุดฝึกเมื่อโมเดลไม่มีการเปลี่ยนแปลงมาก
            1e-4: หากความแม่นยำในการทำนายเปลี่ยนแปลงน้อยกว่าค่านี้ โมเดลจะหยุดการฝึก ช่วยประหยัดเวลา
            1e-6: โมเดลจะฝึกจนได้ความแม่นยำสูงขึ้น แต่จะใช้เวลาเพิ่มมากขึ้น
        threshold: ค่าความน่าจะเป็น (probability threshold) ที่ใช้แบ่งประเภท
            threshold = 0.5 หากความน่าจะเป็นมากกว่า 0.5 จะจัดเป็น class หนึ่ง เช่น "1"
        aggregationDepth = 5: เพิ่มความลึก tree สำหรับข้อมูลขนาดใหญ่ ประมวลผลแม่นยำมากขึ้น (ค่าเริ่มต้น = 2)

Recommendation System
    ALS Parameters
        implicitPrefs: หากเป็นค่าจริง (True) จะใช้ข้อมูลที่ให้คะแนนแบบไม่ชัดเจน (implicit feedback) เช่น 
        การดูรายการหรือการคลิก แทนที่จะเป็นคะแนนที่ชัดเจน ค่าเริ่มต้นคือ False
        alpha: ค่าพารามิเตอร์ที่ใช้ในการปรับน้ำหนักให้กับ implicit feedback เมื่อใช้ implicitPrefs=True 
        ค่าที่สูงขึ้นจะแสดงถึงความมั่นใจที่สูงขึ้นในความหมายของการให้คะแนน
        rank: ระดับของ latent factors (ความซับซ้อนของโมเดล) ที่ใช้ในการทำการคาดการณ์ 
        ค่าเริ่มต้นคือ 10 โดยค่านี้สามารถปรับได้ตามขนาดของข้อมูลและความต้องการของโมเดล
        maxUserIterations: จำนวนรอบสูงสุดที่ ALS จะใช้ในการอัปเดต latent factors สำหรับผู้ใช้ ค่าเริ่มต้นคือ 10
        maxItemIterations: จำนวนรอบสูงสุดที่ ALS จะใช้ในการอัปเดต latent factors สำหรับรายการ ค่าเริ่มต้นคือ 10
        seed: ค่าตัวเลขที่ใช้ในการสุ่มเพื่อให้ได้ผลลัพธ์ที่สามารถทำซ้ำได้
        als = ALS(
            maxIter=10,                  # จำนวนรอบสูงสุดในการฝึกอบรม
            regParam=0.1,                # พารามิเตอร์ Regularization
            userCol="user_id",           # คอลัมน์ที่ใช้ระบุผู้ใช้
            itemCol="book_id",           # คอลัมน์ที่ใช้ระบุรายการ
            ratingCol="rating",           # คอลัมน์ที่ใช้ระบุคะแนน
            coldStartStrategy="drop",     # กลยุทธ์การจัดการข้อมูล cold-start
            implicitPrefs=False,          # ใช้ข้อมูล feedback ที่ชัดเจนหรือไม่
            alpha=1.0,                   # ค่าพารามิเตอร์สำหรับ implicit feedback
            rank=10,                     # ระดับของ latent factors
            maxUserIterations=10,        # จำนวนรอบสูงสุดสำหรับผู้ใช้
            maxItemIterations=10,        # จำนวนรอบสูงสุดสำหรับรายการ
            seed=42                      # ค่าตัวเลขที่ใช้ในการสุ่ม
        )

        autolag: เลือกวิธีการเลือกจำนวนล่าช้า (lags) ที่จะใช้ในแบบจำลอง ADF ค่า 'AIC', 'BIC', หรือ 't-stat'
        เป็นค่าที่สามารถกำหนดได้ ถ้ากำหนดเป็น None จะใช้ค่า max_lags เป็นจำนวนล่าช้าที่กำหนดให้
        max_lags: กำหนดจำนวนล่าชสูงสุดที่ต้องการใช้ในการทดสอบ ADF ค่าดีฟอลต์คือ None
        regression: ค่าที่เป็นไปได้ได้แก่ 'c' (ค่าเฉลี่ย), 'ct' (ค่าเฉลี่ยและแนวโน้ม), หรือ 
        'ctt' (ค่าเฉลี่ย, แนวโน้ม และลำดับที่สอง)
        alpha:
            0.01: ระดับนัยสำคัญที่เข้มงวด ใช้สำหรับการทดสอบที่ต้องการความมั่นใจสูงในการปฏิเสธสมมติฐานที่เป็นศูนย์
            0.05: ค่าเริ่มต้นที่นิยม ใช้ทั่วไปในงานวิจัย สมดุลระหว่างความเสี่ยงในการปฏิเสธสมมติฐานที่เป็นศูนย์และความเชื่อมั่น
            0.10: ระดับนัยสำคัญที่ผ่อนคลาย  หรือเมื่อสามารถรับความเสี่ยงได้มากขึ้น

    การอ่านค่า ถ้าใช้ alpha = 0.05 และได้ p-value = 0.03:
            เนื่องจาก 0.03 ≤ 0.05 จึง ปฏิเสธ H0 อนุกรมเวลาเป็น สถานี
            ถ้าใช้ alpha = 0.05 และได้ p-value = 0.08:
            เนื่องจาก 0.08 > 0.05 จึง ไม่สามารถปฏิเสธ H0 อนุกรมเวลาเป็น ไม่สถานี

        start_q=0: ระบุค่าตั้งต้นของ q เริ่มต้นที่ 0

        start_Q=0: ระบุค่าตั้งต้นของ Q (Seasonal moving average order) เริ่มต้นที่ 0
        max_P=5, max_D=5, max_Q=5: ระบุค่ามากสุดสำหรับ P, D และ Q ตามลำดับ
